# 性格测试技能

## 功能概述
根据用户输入的信息（生日、一句话、照片或答题），生成一份完整的性格分析报告，并保存为美观的HTML文件到电脑桌面。

## 支持的测试方式

### 1. 生日性格测试
**触发条件：** 用户提供了出生年月日（如"1995年6月15日"）
**分析维度：**
- 太阳星座（性格核心）
- 生肖属性（传统性格特点）
- 生命数字（天赋与挑战）
- 性格优势与劣势
- 恋爱模式
- 适合职业方向

### 2. 一句话心理投射测试
**触发条件：** 用户输入了一句话或描述了一个场景/感受
**分析维度：**
- 潜意识投射分析
- 当前心理状态
- 性格底层逻辑
- 情绪模式
- 改善建议

### 3. MBTI正式测试
**触发条件：** 用户明确要求做MBTI/16型人格测试
**执行流程：**
1. 从4个维度各出2-3道题，共约10-12题
2. 用户逐题作答
3. 根据答案计算4个维度倾向（E/I, S/N, T/F, J/P）
4. 得出最终类型（如INFP、ESTJ）
5. 生成完整分析报告

### 4. 照片性格分析
**触发条件：** 用户上传了人像照片
**分析维度：**
- 面相性格倾向
- 气质类型判断
- 整体印象分析

## 报告输出规范

### 文件保存
- 格式：HTML单文件
- 保存位置：电脑桌面
- 文件名：`性格测试报告_YYYYMMDD_HHMM.html`

### 报告内容结构
1. 标题：【性格测试报告】
2. 用户输入信息（生日/一句话/类型结果）
3. 核心结论（一句话总结）
4. 详细分析（分维度展示）
5. 性格雷达图（用纯CSS/SVG绘制）
6. 建议与寄语

### 视觉风格
- 清新简约风格
- 主色调：淡紫/深蓝渐变
- 卡片式布局
- 响应式设计，手机也能打开
- 不依赖外部资源，单文件可直接打开

## 执行步骤

1. **判断测试类型**：根据用户输入内容，确定使用哪种测试方式
2. **收集信息**：如果是MBTI测试，先出题让用户作答
3. **生成分析**：基于输入内容进行多维度性格分析
4. **生成HTML报告**：按照规范生成美观的HTML文件
5. **保存到桌面**：将报告文件保存到用户电脑桌面
6. **告知路径**：告诉用户报告已保存的位置

## 注意事项
- 性格测试结果仅供娱乐参考，不构成专业心理诊断
- 分析语言要积极正面，避免负面标签
- 报告要美观易读，有分享欲望
- 生成的HTML文件必须能直接双击打开，不需要任何服务器
